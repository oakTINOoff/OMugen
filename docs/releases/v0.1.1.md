Fixes found by testing OMugen on a second MUGEN game (852x480, 50 characters, 4:3 and
16:9 stages, HD lifebars), and a friendlier first start.

## Install

Download **`OMugen-v0.1.1-windows.zip`** below, unzip it and copy `OMugen.exe` into your
MUGEN 1.1 game folder, next to `mugen.exe` (replace the old one if you have it).

> Windows may warn that the app is unrecognized, because the exe isn't signed yet:
> click **More info**, then **Run anyway**.

## What's new

- **Your game's own rules.** The first start in a game folder takes the game's settings
  from `mugen.cfg`: life, round time (including "no time limit"), difficulty, game speed,
  team options, volumes, arcade AI and how stages fit the screen. The game plays as it
  does in MUGEN. Changes made later in Options are saved to `mugen.cfg` too. Games you
  already played with OMugen keep the settings you chose.
- **Widescreen like MUGEN 1.1.** A 4:3 stage in a widescreen game fills the screen, cut
  at the top and bottom as the stage's `cuthigh`/`cutlow` say, instead of sitting between
  black bars with the lifebars squeezed in. Games with `StageFit = 1` in `mugen.cfg` keep
  the shrink-to-fit look.
- **Started outside a game folder** (say, right after unzipping), OMugen no longer
  crashes: it says where it belongs and offers to create a new game of your own there.

## Fixes

- The first start no longer replaces the game's `mugen.cfg` controls with default keys
  (numpad players couldn't even skip the intro).
- Quick matches (`-p1`/`-p2`) showed no lifebars when the lifebars don't set their own
  `localcoord`.
- A game whose `select.def` is missing gets a clear message instead of a script error.
- Move list icons: "hold forward" was missing and "hold up-forward" showed the half-circle
  icon.

`SHA256SUMS.txt` lists the checksums of the downloads.
