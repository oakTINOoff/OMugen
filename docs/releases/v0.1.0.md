The first release of **OMugen**: your M.U.G.E.N game, unchanged, on a modern 64-bit engine.

## Install

1. Download **`OMugen-v0.1.0-windows.zip`** below and unzip it.
2. Copy `OMugen.exe` into your MUGEN 1.1 game folder, next to `mugen.exe`.
3. Run it.

Nothing in the game folder is changed: OMugen only adds a `save` folder (settings, logs,
replays). The first start unpacks the engine files to `%LOCALAPPDATA%\OMugen\engine`.

> Windows may warn that the app is unrecognized, because the exe isn't signed yet:
> click **More info**, then **Run anyway**.

## What's in it

- **Drop-in MUGEN 1.1:** the game's own characters, stages, screenpack, lifebars and
  `mugen.cfg` controls, with MUGEN's exact key and joystick codes. Changes in Options are
  saved back to `mugen.cfg`.
- **Controllers for up to 4 players:** DualShock 4, DualSense and Xbox pads over USB or
  Bluetooth, no DS4Windows needed. Light bars show the player's color; menus show who is
  selecting.
- **Fast with big rosters:** a 1,580-character game reaches the menu in about 2 seconds.
- **Smooth on 120-240 Hz monitors** (Options > Video > Frame Rate), with gameplay
  unchanged: still 60 ticks per second.
- **Online and LAN play.**
- **Built-in screenpack and lifebars** that take over when a game's own fail to load.
- **OMugen Doctor:** `OMugen.exe -doctor` checks every character and stage and writes a
  report.
- **Make your own game:** `OMugen.exe -newgame "My Game"` creates a playable game with
  Proto (an armored android fighter), the Proto Arena rooftop dojo, menus and lifebars.

## Good to know

- **Linux:** `OMugen-v0.1.0-linux.tar.gz` is an early build (unpack it into the game
  folder, keeping `OMugen_Linux` and `lib/` together). It builds and passes the tests, but
  hasn't been played on Linux yet.
- **Online play** has only had light testing so far.
- Found a problem? [Open an issue](https://github.com/oakTINOoff/OMugen/issues/new/choose) with the newest file from
  `save/logs`.

`SHA256SUMS.txt` lists the checksums of the downloads.
